\# Reflex Delivery System 🚚



Digitizing last-mile delivery for Kenya’s small retailers.  

Reflex replaces informal WhatsApp/phone coordination with a transparent, trackable workflow for retailers, dispatchers, and riders.



---



\## ✨ Features

\- \*\*Retailer Portal:\*\* Log new delivery requests with customer name, phone, address, and item description.

\- \*\*Dispatcher Dashboard:\*\* View open requests and assign them to riders in real time.

\- \*\*Rider App:\*\* Track assigned deliveries and update status transitions (Assigned → Picked Up → Delivered).

\- \*\*Sync \& Scan:\*\* Real-time request syncing and QR-based order confirmation for proof of delivery.
